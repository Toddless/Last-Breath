# Концепты предметов и пулов модификаторов

> Черновые описания от Todd (сессия 2026-07-03). **Значения пока что очень условные.**
>
> Типы модификаторов предметов (по силе, слабейший → сильнейший):
> - **flat** — плоское значение («X +800»);
> - **increase** — аддитивный процент («увеличение X +30%»), инкризы суммируются;
> - **multiplier** — мультипликативный процент («увеличение X на 30%»), самый сильный тип.
>
> Расчёт параметра: `(сумма flat × (1 + Σ инкризов)) × (1 + мультипликативы)`.
>
> Повторяющиеся названия предметов (варианты) = механика придумана, название ещё не придумано.
