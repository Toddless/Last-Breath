# VFX способностей — источники

Плейсхолдер-VFX собраны из бесплатных паков (нарезаны на кадры, перекрашены под элемент) + генерация.

| Пак | Лицензия | Использование |
|---|---|---|
| Brackeys' VFX Bundle (predrawn) | CC0 (атрибуция не требуется) | charge→cast, explosion/electric_ring/fire_point→impact, big_hit/impact_white/blood_impact→ближний, vortex/wavy_blue/wavy_purple→ауры баффов |
| Pure Projectile (OpenGameArt) | CC0 (сверить на странице) | снаряды (projectile), тонированы под элемент |
| Arcane Effect (OpenGameArt) | CC0 (сверить) | в запасе, не задействован |
| Сгенерировано (Ice Shards) | — | cast/projectile/impact/impact_crit |

Brackeys — CC0, кредит не обязателен. Для OpenGameArt-паков стоит открыть страницу и подтвердить лицензию (CC0/CC-BY) перед релизом.
