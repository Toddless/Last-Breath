# Кейстоуны: спецификация пассивок к реализации

**2026-08-27, черновик ведущего на правку владельца.** Формулировки взяты из «Боевые искусства → Список кластеров по клиньям» (имена владельца). После правок владельца каждый блок уходит исполнителю как есть. Уже живущие в дереве (Бесконечная мощь, Танец смерти, Ядовитый укус/keystone_7) не включены.

## A. Закрываются данными — класс не нужен

| Кейстоун | Клин | Поля стат-пассивки (`Passive_Skill_Stats_<Имя>`) |
|---|---|---|
| **Холодный разум** | Интеллект | `ColdDamage:Increase:Mana:15` = 0.02 (после #212 — «2% за каждые 15 маны» буквально) |
| **Повелитель стихий** | Интеллект | `AllElementalDamage:Increase:Intelligence` = 0.01 |
| **Меткость** | Ловкость+Сила | `Accuracy:Flat:Dexterity` = 5 |
| **Разум превыше материи** | Интеллект+Ловкость | `Barrier:Flat:Intelligence` = 3 + `BarrierRecovery:Multiplicative` = −0.35 |

Расставляешь в редакторе сам, кода ноль.

## B. Классы к написанию (формулировки решены)

### 1. Стоицизм (Сила) — «Не подвержен контролю. От атак невозможно уклониться»
- **Иммунитет к контролю**: пассивка вешает модификатор входящих эффектов (образец `ControlResistanceModifier`): эффект с жёстким контролем (`HardControlMask` — стан/фриз и родня) получает `Rejected = true`. ~30 строк.
- **Расплата — сам не уклоняется**: гейт в точке ролла уклонения (`ResolveAttackOutcome`), по контекст-флагу защитника (новая ручка вида `CannotEvade`, которую ставит пассивка). Дисциплина RNG как у блока (#207): **бросок жжётся всегда, гейтится исход** — сид-потоки не сдвигаются.
- Обе половины — одна пассивка `Passive_Skill_Stoicism`, полей-чисел нет.

### 2. Яростный укус (Ловкость) — «+1% мульт. яда за ед. сопротивления яду свыше потолка. Сопротивление яду −60%»
- **Класс-близнец скейла**: `ScaledByOvercapModifier` — как `ScaledByParameterModifier`, но носитель = `max(0, тотал сопротивления − эффективный максимум)` из `ResistanceParameters` (излишек уже считается там же, где кап).
- Поле пассивки: доля за единицу излишка (0.01 → `PoisonDamageMultiplier`).
- **Расплата данными**: строка `PoisonResistance:Multiplicative` = −0.6 в той же пассивке.
- Замечание балансное: −60% сопротивления РЕЖЕТ и излишек — кейстоун сам у себя отъедает носителя; так задумано (излишек надо перекормить)? Да, так и задумано. При достаточных вложениях в сопротивление яду кейстоун дает большое кол-во мультипликатора, но набрать большой общий % сложнее. Иначе это бесплатный урон за 0. 

### 3. Железная воля / Ветер свободы / Агностик — один общий класс конверсии пула
- **`Passive_Skill_Pool_Conversion`** (один класс, три записи с полями `from`/`to`): «весь параметр A конвертируется в B» = два модификатора от имени пассивки: `B += X (Flat)` и `A ×0 (Multiplicative −1)`, где **X = значение A, посчитанное БЕЗ вкладов самой пассивки** (резолв по списку модификаторов с исключением своего source — иначе замыкание).
- Живая подписка: пересчёт X при `ParameterChanged` источника (снял кольцо с уклонением — броня от Железной воли усохла).
- **Железная воля**: Evade → Armor. **Ветер свободы**: Armor → Evade. **Агностик**: Mana → Health, плюс к той же пассивке готовые модификаторы активации: стоимость здоровьем (`CostTypeActivationContextModifier(Costs.Health)`, образец BloodSeal) и +25% стоимости (`CostScaleActivationContextModifier`, образец CloudedMind).
- Вопрос владельцу: у Агностика конверсенная прибавка к здоровью — 1:1? Да.

### 4. Дар природы (Сила+Интеллект) — «Весь элементальный урон +35%. Атаки не наносят физический урон»
- **+35% элементаля — данными** внутри пассивки: `AllElementalDamage:Multiplicative` = 0.35 (More — по правке владельца; конвенция «увеличен НА X%» = More зафиксирована в журнале).
- **Обнуление физа — в контексте удара** (решение 2026-08-25: параметр сущности не трогается): новый `IDamageModifier`, зануляющий Physical-компоненту словаря урона атаки (~20 строк, приоритет после конверсий — Absolute-сосед).
- Пограничное: физ-компонента, уже конвертированная мификами в стихию (`PhysicalToFire` и родня), уходит В КОНВЕРСИЮ раньше и не гасится — так и задумано (конверсии дружат с кейстоуном)? Да.

### 5. Сила духа (Сила+Интеллект) — «35% шанс восстановить 5% максимума маны ПРИ ПОЛУЧЕНИИ удара. Восстановление маны −25%»
- Пассивка-подписчик на получение удара носителем (шаблон `GiftFromTheGoddessPassiveSkill` — там же событийная подписка и `ChanceRoll.Roll`): шанс 0.35 → +5% от МАКСИМУМА маны.
- Поля: `chance` = 0.35, `percentOfMaxMana` = 0.05.
- Расплата данными: `ManaRecovery:Multiplicative` = −0.25.
- Уточнение: «удар» = любой входящий хит с уроном (включая DoT-тик?) — предлагаю ТОЛЬКО прямые удары (Attack/Hit/Projectile/ChainJump/Splash), тики НЕ считаются, иначе яд кормит ману каждую итерацию. // Верно, только прямые удары

## C. Нужна твоя правка формулировки до кода

### 6. Ярость стихий (Интеллект+Ловкость) — «Атаки пробивают элементальные сопротивления на значения свыше потолка. Сопротивления снижены на 45%»
Моё прочтение (поправь): атаки носителя получают элементальную пенетрацию, равную **излишку цели над ЕЁ потолком** (оверкап-запас цели перестаёт защищать от этого атакующего; у цели без излишка пробития нет). // Считаем оверкап носителя. Т.е в данном случае игрок. К примеру при 120% тотал сопротивления к холоду получаем пробитие холода равные 120-75 = 45%. И так для всех стихий. 
Расплата: **свои** сопротивления −45% (тотал, по конвенции шреда — бьёт запас, не потолок): `AllResistance:Multiplicative` = −0.45 данными.
Реализация: контекст-модификатор атаки (образец `IgnoreResistancesContextModifier`), читающий `ResistanceParameters` цели в точке митигации.

### 7. Триединство (Интеллект+Ловкость) — «Атаки наносят 100% физического урона как холод, огонь, молния»
Моё прочтение (поправь): физическая компонента атаки **добавляется** стихийной добавкой, разложенной поровну — по 33.3% физа в холод, огонь и молнию (итого +100% суммарно), сам физ **остаётся**. Альтернативы, если имелось в виду иное: (а) по 100% в КАЖДУЮ стихию (+300%); (б) конверсия — физ исчезает, появляются три стихии по 33.3%. // Вариант Б. 
Реализация: `IDamageModifier` по образцу добавок `AddedFire/Cold/LightningDamage`, читает Physical-компоненту, сеет три стихийных.

## Порядок работ после твоих правок
Волна одним заходом: класс конверсии (закрывает три кейстоуна) → Стоицизм → Яростный укус (+близнец скейла) → Дар природы → Сила духа → (Ярость стихий, Триединство — после правок этого файла). Каждая пассивка: регистрация в реестре + запись в `PassiveCatalog.json` (синхро-тест сам заставит) + пины + ревью.
