# NPC в общей системе взаимодействия — #266

## Цель и состав

Подключить разговор и явную атаку к выбранному объекту и общей клавише E. Основа — согласованная архитектура #264 и реализация #265. Ограбление остаётся отдельным этапом.

## Сцены и свойства

В общей сцене NPC вместо кликабельного DialogueActor размещается NpcInteractionTarget с общей геометрией обнаружения, InteractionPoint и HintAnchor. Его дочерние компоненты DialogueActor и NpcAttackActionSource предоставляют независимые действия. DialogueActor становится обычным компонентом без собственного ввода.

Идентичность цели берётся из InstanceId живого NPC, а не из ID его вида. При переносе в арену регистрация снимается, после возвращения создаётся новая привязка. Старые команды не работают с вернувшимся объектом. Статический собеседник использует обычный InteractionTarget с авторским ObjectId и дочерний DialogueActor с _npcId и _faction; атака без боевого тела отсутствует.

Точки взаимодействия задаются возле ног. Подгонка физических коллайдеров под изображение NPC больше не меняет радиус обнаружения и не требует старой области клика диалога.

## Доступность

| Состояние | Представление |
| --- | --- |
| Живой свободный NPC, canTalk и подходящий вход в диалог | Поговорить доступно. |
| NPC не умеет говорить | Поговорить отсутствует. |
| NPC умеет говорить, но диалога/подходящего входа нет | Поговорить недоступно с пояснением. |
| Живое свободное боевое тело, игрок может начать бой | Атаковать доступно, всегда требует отдельного выбора в меню. |
| NPC мёртв, в бою, в другом пространстве либо за препятствием | Взаимодействие не выполняется; открытое меню закрывается. |

Репутация сама по себе не запрещает разговор: это решают существующие условия входа. Нападение по инициативе игрока доступно и для нейтрального существа; контакт с нейтралом по-прежнему не запускает бой. Новые штрафы репутации за начало боя не вводятся: действуют существующие деяния и последствия убийства.

## Проверка диалога без побочных эффектов

IDialogueService.CanStart проверяет каталог и правила входа, не вызывает Start/End, не начисляет опыт, не выполняет действия узла и не проверяет варианты реплик. Start использует тот же порядок разрешения входа.

Условия явно объявляют пригодность для предварительной проверки; новые неизвестные условия по умолчанию запрещены. AllOf/AnyOf/Not безопасны только при безопасности всех вложенных условий. QuestOfferRoll запрещён во входах. CanAcceptQuest также не допускается во входах: его косвенные условия принятия могут иметь побочные эффекты. В вариантах реплик оба условия сохраняют прежнюю работу во время настоящего разговора. Неподдерживаемый вход отклоняет диалог с диагностикой при загрузке данных.

## Запуск и завершение

Разговор передаётся существующему обработчику открытия диалога через GameMessageBus. Атака идёт через общий с контактом метод запуска боя: существующий отбор живых свободных членов группы, BattleInitializedEvent, арена, маркер и шум. Позиция и пространство шума фиксируются до переноса участников.

Перед выполнением команды повторяются проверки выбранной цели и действия. Меню блокирует ходьбу игрока, мир продолжает работать. После передачи управления диалогу контролируется доступность собеседника; потеря близости, преграда, смерть или бой завершают разговор.

## Проверка

Управляемые тесты: отсутствие изменений фактов/опыта/RNG при CanStart; общая приоритетность входов; отказ вложенным опасным условиям и косвенному CanAcceptQuest; сохранение поведения реплик.

Внутри Godot: меню у нейтрального NPC, отсутствие разговора по клику, явный разговор/атака, движение и смерть NPC при открытом меню, преграда, устаревшая команда, возврат из арены и повторная регистрация. Регрессия: сундук, путешествия, физическая изоляция.

## Результат реализации

Выполнено: общая сцена NpcInteractionTarget, компоненты разговора и атаки, отказ от кликового входа в диалог, безопасная проверка входов и контроль доступности текущего собеседника. Статические собеседники сохраняют авторские _npcId/_faction.

При запуске боя группа больше не помечается целиком как сражающаяся: BattleContext изменяет состояние только допущенных участников. Свободные члены группы в другом пространстве остаются свободными; занятые другим боем продолжают его.

Проверено:
- NpcInteractionTest — 37 проверок внутри Godot, включая нейтральный контакт, явный выбор атаки, статического собеседника, смену доступности, группы, шум и возврат из арены.
- DialogueAdmissionTests — 4 теста без нативных объектов Godot.
- Регрессия внутри Godot: InteractionTest — 38, LocationTravelTest — 34, SpaceIsolationTest — 31.
- Расширенный прогон диалогов/нарративных данных/UI: 88 из 96 тестов проходят. 8 ошибок связаны с уже существующим в HEAD дефектом Quest_Field_Of_Bones: у счётчика GatherProof/Revenants отсутствует key. Квест отклоняется при загрузке, что ломает связанные сценарии ветерана. Данные квеста в этом этапе не менялись.
- Сборка Main и Testing успешна. При отдельном запуске редактора для импорта были ошибки загрузки библиотеки Effekseer; последующий запуск игровых тестовых сцен завершился успешно.
